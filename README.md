# Ayush Srivastava — Portfolio

### Full-Stack Developer Portfolio

A modern, dark-themed, single-page portfolio built with React, Vite, and Framer Motion — featuring smooth scroll navigation, an AI-powered chatbot, and a fully functional contact form.

## ✨ Features

- **Single-Page Layout** — Smooth scroll navigation between sections
- **AI Chatbot Assistant** — Powered by Google Gemini, answers questions about my portfolio
- **Functional Contact Form** — Netlify Functions + Brevo for automated email replies
- **Dark Modern Theme** — Cyan & purple accents with glassmorphism touches
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Smooth Animations** — Framer Motion & Lottie animations
- **Google Analytics** — Integrated with react-ga4

## 🛠️ Tech Stack

### Frontend
| Technology | Purpose |
|------------|---------|
| **React 19** | UI library |
| **Vite** | Build tool & dev server |
| **Framer Motion** | Animations |
| **Lottie React** | JSON-based animations |
| **React Icons** | Icon library |
| **Bootstrap 5** | Grid & utility classes |

### Backend / Serverless
| Technology | Purpose |
|------------|---------|
| **Netlify Functions** | Serverless API endpoint |
| **Google Gemini API** | AI chatbot responses |
| **Brevo (Sendinblue)** | Transactional email service |

### Analytics & Deployment
| Technology | Purpose |
|------------|---------|
| **React GA4** | Google Analytics integration |
| **Netlify** | Hosting & deployment |
